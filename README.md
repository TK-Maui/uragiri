# ウラギリ（テストプレイ版）

ダンジョン探索 × 正体隠匿のチーム対抗カードゲーム「ウラギリ」を、ブラウザで遊べるテスト版です。

- **オンライン版（index.html）**：それぞれのスマホで同じ部屋に入って遊びます。1人が「部屋を作る」を押し、ほかの人は部屋コードか招待リンクで参加します。端末同士を直接つなぐ方式（WebRTC / PeerJS）なので、サーバーやアカウントは不要です。
- **1台回し版（pass.html）**：1台の端末を順番に回して遊びます。

## オンライン版の注意

- 部屋を作った人（ホスト）の画面にゲームの状態がすべて入っています。ホストはゲーム中、ページを閉じたりスリープさせたりしないでください。
- 誰かの接続が切れても、同じ端末で同じリンクを開けば自動で戻れます。
- 戻れない人の手番は、ホストが代わりに終わらせられます。
